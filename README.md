# coredeltavwebsitev2

Official website and creative portfolio for **coredeltav™** — Creative Director, visual storyteller, and content creator based in Kathmandu, Nepal.

## Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + Radix UI (shadcn/ui)
- **Routing:** React Router v6
- **Animations & Smooth Scroll:** Framer Motion, Lenis, Embla Carousel
- **State Management:** Zustand
- **Deployment:** GitHub Pages / Custom Domain

## Getting Started

### Development
```sh
bun run dev
# or: npm run dev
```
Starts the local development server at `http://localhost:8080/`.

### Production Build
```sh
bun run build
# or: npm run build
```

### Preview Build
```sh
bun run preview
# or: npm run preview
```

### Deploy to GitHub Pages
```sh
bun run deploy
# or: npm run deploy
```
